# ⚡ Real-Time FPGA Buck-Boost Converter

A real-time simulation platform for DC-DC Buck-Boost converters implemented on a **Xilinx PYNQ-Z2 FPGA** using **MATLAB**, **Simulink**, **Simscape**, and **HDL Coder**.

This project demonstrates the complete workflow from converter modeling to automatic HDL generation, FPGA deployment, and real-time validation.

---

## 📖 Project Overview

The objective of this project is to develop and validate a real-time FPGA implementation of a DC-DC Buck-Boost converter.

The design was modeled in MATLAB/Simulink and Simscape, automatically translated into synthesizable HDL using HDL Coder, and deployed on a Xilinx PYNQ-Z2 FPGA. The resulting platform enables real-time execution and allows a direct comparison between CPU- and FPGA-based implementations.

---

## 🚀 Main Contributions

- Design and modeling of a DC-DC Buck-Boost converter
- Automatic HDL generation using MATLAB HDL Coder
- Development of a **32-bit PWM generator**
- Integration of a **PI controller**
- Deployment on a **Xilinx PYNQ-Z2 FPGA**
- Real-time visualization using **MATLAB** and **Jupyter Notebook**
- Performance comparison between **CPU** and **FPGA** execution
